# 💬 Gemini Chatbot (Python)

A simple command-line chatbot powered by **Google's Gemini API** using the `google.generativeai` package.

> 🔒 **Note:** The API key is stored securely using an `.env` file, so this chatbot won't work for others unless they provide their own Gemini API key.

---

## ⚙️ Requirements

- Python 3.8+
- `google-generativeai`
- `python-dotenv`

Install dependencies:
```bash
pip install google-generativeai python-dotenv
